# CountryLens 🌎

A modern, interactive dashboard for exploring countries worldwide. Built with Next.js and the REST Countries API, CountryLens offers a sleek interface to discover, compare, and visualize country data with powerful filtering, sorting, and mapping capabilities.

## ✨ Features
- 🔍 Advanced search and filtering by region, population, and alphabetical order
- 📊 Side-by-side country comparison tool
- 🗺️ Interactive map explorer
- 🌓 Dark/light theme toggle
- 📱 Fully responsive design for all devices
- ⚡ Smooth animations and transitions

## 🛠️ Tech Stack
- Next.js (App Router)
- React.js
- REST Countries API
- Google Maps integration
- Custom CSS with Tailwind-inspired variables
